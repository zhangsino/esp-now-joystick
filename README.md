# esp32_now —— 摇杆 → ESP-NOW → 小屏

用两块 ESP32-S3 把一个 DJI RC2 摇杆变成一条**不依赖 Mac、不依赖路由器**的无线控制链路：

```
RC2 ──USB──> 发送板（手持端）          ESP-NOW 2.4G        接收板（无头盒子）
              USB Host 247Hz  ──── 摇杆包 50Hz ────────>
              OLED 128x64     <─── 状态包 5Hz ──────────   收包 + RGB 动作灯
```

- **屏在发送板上**。插上 RC2 先出 `RC2 CONNECTED`，然后显示实时画面。
- **接收板没有屏**，只有一颗 RGB 灯：动左摇杆=红、动右摇杆=绿、按键=蓝、三个一起=白、静止灭。
- 两边互发，发送板知道"我发的包对方收到了"（顶栏那个百分比）。

- 发送端的 USB HID 代码不是新写的：从 `~/esp/rc2_web`（已在板上跑通 247 Hz）搬过来的，
  只砍掉网页/WebSocket，换成每 20 ms 广播一包。
- 接收板是"通用 ESP-NOW 显示屏"：以后小车、平衡车、云台都可以往它发，不用再改这块板。

## 2. 接线

### 发送板 → OLED（4 针 I2C）—— 屏接在**发送板**上

| OLED | 接发送板 |
|---|---|
| VCC | **3V3**（不要接 5V） |
| GND | GND |
| SDA | **GPIO 17** |
| SCL | **GPIO 18** |

地址 0x3C，和以前 `esp32/tilt.py` 用的完全一样（SDA=17 / SCL=18 / 400 kHz）。
**插线前对着丝印核一遍 17、18**，别把 7 看成 17。

### 发送板 → RC2

RC2 插板子上**丝印 `USB`（原生 USB / OTG）那个口**，不是 `UART` 口。
两个口都能插 Type-C，插错了就是"枚举不到设备"：
- `UART` 口（板子上的 CH343 芯片）→ 给你连 Mac 烧录、看日志
- `USB` 口（GPIO19/20）→ 给 RC2

> 已实测（`~/esp/rc2_web` §8）：**板子原生 USB 口不往外供 5V**。RC2 自带电池，
> 不需要板子供电，所以照样能读。别为这事纠结。

## 3. 烧录

两个工程各自独立编译，别在同一个窗口交叉使用。

**第一次先把环境加载好**（每个新终端都要）：

```bash
source ~/.zshrc && get_idf
```

**找串口**（每次插拔名字都可能变）：

```bash
ls /dev/cu.wchusbserial*
```

**烧接收板**（板子插的是芯片原生 **USB** 口，串口名是 `usbmodem...`）：

```bash
cd ~/esp32_now/receiver
idf.py -p /dev/cu.usbmodem1101 flash monitor
```

> 这块板子的固件里开了 `CONFIG_ESP_CONSOLE_SECONDARY_USB_SERIAL_JTAG=y`，
> 所以原生 USB 口既能看到日志、也能直接烧录（会自动复位，不用按 BOOT）。
> 只有**第一次**从别人的固件烧进来时要 BOOT+RST 手动进下载模式。

**烧发送板**：

```bash
cd ~/esp32_now/sender
idf.py -p /dev/cu.wchusbserial5D280919831 flash monitor
```

`monitor` 里按 `Ctrl+]` 退出。烧完拔掉再插上就是正常运行。

## 4. 怎么用

1. 两块板都上电（各自随便供 5V，户外用充电宝，见 §6）。
2. 发送板串口每秒钟打一行 `rc2=1 hz=247 ...`，说明 RC2 认到了。
3. 接收板屏上出现 `xxHZ -45DB L0` + 两个摇杆盘 + 24 个按键点。
4. 没有 RC2 也能先验接收板：**按一下发送板上的 BOOT 键**，切到模拟扫动数据（再按一次切回）。

### 屏上怎么读

| 位置 | 含义 |
|---|---|
| 顶部 `100%   +8dB D +12 L0` | **发送成功率** · **接收板看到的信号** · **拨盘值 D**（回中 0，±660 到头） · **丢包 L** |
| 大字 `RC2 CONNECTED` | 刚插上 RC2 的那两秒 |
| 大字 `PLUG IN RC2` | 没认到 RC2 |
| 顶部 `NO LINK` | 收不到接收板的状态包了（接收板断电/太远） |
| 左盘 | **左摇杆**：横 = 左右（Rz），竖 = 油门（Z，**没有回中弹簧**，杆停哪算哪） |
| 右盘 | **右摇杆**：横 = 左右（X），竖 = 上下（Y） |
| 底部 24 点 | 按键位。**上排 bit0–11，下排 bit12–23**，实心 = 按下 |

按键名对照（`car_spy/README.md` 实测）：bit0=C1，bit1=start/stop，bit2=暂停/返航，
bit3=拍摄/录像；bit4/5 = 右三态开关（中/下），bit6/7 = 左三态开关（下/上）。

### 参数在哪改

| 想改 | 改哪 |
|---|---|
| 信道（默认 11） | 两个 `main.c` 顶部的 `NOW_CHANNEL`，**两端必须一样** |
| 发送频率（默认 50 Hz） | `sender/main/main.c` 的 `SEND_PERIOD_MS` |
| 屏幕刷新（默认 33 ms） | `receiver/main/main.c` 里 `vTaskDelay(pdMS_TO_TICKS(30))` |
| 报文格式 | `common/now_proto.h`，改完两端重烧 |

## 6. 户外供电

**RC2 自己有电池，板子只需要供 ESP32 自己**，实测整板约 100 mA 量级（含 ESP-NOW 发射）。

| 方案 | 怎么接 | 优点 | 缺点 | 量级 |
|---|---|---|---|---|
| **① 充电宝（推荐）** | USB-A → USB-C 线插板子 `UART` 口 | 有保护、不用焊、到处能买 | 户外看不到串口日志（本来也不用） | ¥60–100 / 10000 mAh |
| **② 2×18650 电池盒 + 降压模块** | 7.4 V 经 MP1584 降到 5 V，接 5V/GND 排针 | 可换电池、能撑很久 | 要接线，电池要单独充 | ¥40–60 |
| **③ 6×AA 碱性盒** | 9 V 经降压到 5 V | 最便宜 | **不推荐**：内阻大，发射瞬间压降容易复位；电压随电量一路下滑 | ¥15 |

- ①最省事，先买这个；想要"换电池继续飞"再上 ②。
- 别把 3S 锂电池直接怼 5V 脚，会烧。要么走降压模块，要么走 USB 口。
- 充电宝注意：**有些带自动断电的会以为"没在充电"而关掉输出**（电流太小），
  选带"小电流模式"的，或者选按键唤醒的。

## 7. 已知风险 / 还没验证的

- **接收板的 OLED 型号**按 128x64 SSD1306 写死（和以前那批屏一致）。若你的屏是
  0.96 寸以外的 SH1106/7 针 SPI，驱动要改。
- **两板同时上电的顺序**没测过：现在谁先上电都行，先上电的那块一直广播/监听。
- ESP-NOW 距离没测。参考 r3car 的 WiFi 实测：20 m 内 −70 dBm 够用，ESP-NOW 通常同量级。
